## 下一步

1. 修复并回归“记忆工具输出被自动抽取再次写入”的问题；桌面真实模型验收中出现一条跨类型重复内容，不能简单按文本合并。
2. 扩大实体面板真实使用题和异常场景，收集实际使用问题；首轮合成桌面操作已完成。
3. 相同预算验证实体检索、任务相关记忆包和确定性缓存，减少无关上下文与重复计算。
4. 为 Super Agent 明确项目/工单作用域、事件去重与集中写回执，复用原型。
5. 在 0.9.1 隔离合成库评估文档证据与命名图，有收益和兼容性证据后再决定接入。

真实模型测试中，`ctx_remember` 写入了合成 preference；新会话使用 `ctx_find` / `ctx_read` 成功找回。随后自动抽取又把同一正文写成 entity，记录来源为 tool。它证明工具输出可能被作为新记忆重复抽取；这次只观察到一例，原因与避免误杀新事实的方案仍需专项回归，本轮没有自动合并或删除节点。
