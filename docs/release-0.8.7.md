# 0.8.7 — 替代变成提案

2026-11-09。**内核不变**（仍是 `triviumdb@0.9.0`，那一步在 0.8.5 单独发过）。
这一版只改一件事：**"改口"不再自动退休决策**。

## 变了什么

### 自动路径只记录提案，不再建替代边

0.8.6 及更早：只要措辞看起来像改口，抽取就直接写 `supersedes` 硬边，旧决策退出短地图。
四轮复审证明**措辞不是授权**——模型给出显式替代字段时同样会误退休。

现在：

- 抽取只在新节点上写 `review: "supersede-proposed"` 与候选目标 `proposedSupersedes: [id…]`；
- **旧决策仍是当前版本**，没有边，`ctx_find` / `ctx_read` 都照常返回；
- 目标有歧义时（两条都叫"方案 A"）**把全部候选都记下来**，由人挑一个，不猜。

### 由人确认，且确认前会重新核对

| 动作 | 接口 |
|---|---|
| 看待确认列表 | `GET /api/dsh-trivium/supersede-proposals` |
| 确认某一个候选 | `POST /api/dsh-trivium/supersede-proposals/<id>/confirm`（body 带 `targetId` 与 `etag`） |
| 保持原样 | `POST /api/dsh-trivium/supersede-proposals/<id>/reject` |

确认在**写锁内**重新判定：这条提案仍待确认、目标仍在候选里、目标仍存活、这条边还不存在、
`etag` 未变。任一不满足返回 409，不会"按旧页面把边写回去"。

确认走的是既有修订校验（`revisions.supersede`），自环、循环、归档、已替代、链长都在同一处判断。

### 拒绝会留下墓碑

拒绝不是删除：事实本身保留，仍然现行。拒绝的目标记进 `rejectedSupersedes`，
**通用修订接口对同一对返回 409**——旧标签页或旧客户端不能再把刚被拒绝的边写出来。
同一事实之后再次被提案时，墓碑会被新提案清掉（那是新的意图），旧标签页由 `etag` 拦住。

### 写接口都进工作区锁

确认、拒绝、修订、撤销四类写路由与导入一样取工作区写锁；另一个进程正在写时返回 409
`WORKSPACE_WRITE_BUSY`，不再出现"面板说成功、库里锁着"的情况。

### 失败如实上报

- 提案标记写不进去：抽取报 `proposal-failed`，**不报"已提案"**（事实上提案列表里也没有）；
- 边已建立但清除标记失败：返回 200 + `warning: "marker-not-cleared: …"`，不再用 500 掩盖已经发生的事。

### 诊断补了三项

- `mapInjections.sessionStart`：会话启动注入单独计数（`full` 仍然只数刷新阶段）；
- `lastScreen.keptByToolEvidence`：本会被判 0 分、因带工具结果而保留的组数；
- `lastMapInjection.sessionId`：工作区级诊断现在能看出是哪一次会话。

### 面板

「运行记录」页新增**待确认替代**卡片：每条列出提案正文、原句、每个候选一行（确认/保持原样）。
确认与拒绝都只影响这一条，不提供"全部确认"。

## 升级注意

- **0.8.6 已经自动建立的替代边保持原样**，不回滚。无法可靠判断哪些是当时真正的改口，
  批量回滚会把正确的替代一起打回。有争议的关系用既有撤销入口逐条处理。
- 逃生口：`~/.dsh/trivium.json` 的 `supersedeMode: "auto"` 恢复 0.8.6 的自动建边行为，
  缺键或 `"propose"` 是默认的提案模式。面板不暴露这个开关。
- **模型工具契约没有变化**：没有新增 `supersedes_id` 之类的参数。模型不能确认替代——
  不是"权限隔离"，而是模型这条路径根本不提供确认能力。

## 已知限制

1. **召回**：未确认期间两条决策都现行，模型可能按旧值回答。这是 P 的代价，面板标记只能提示。
2. **"都现行"不等于"都在地图里"**：短地图有 8 个命名槽位与 token 预算，两条都有资格入选，
   但库大时可能只有一条被展开。
3. **计轮依赖宿主暴露用户消息**：从不在任何窗口给出用户消息的宿主不会触发 6 轮全量；
   轮次计数的修复仍只有离线证据，**没有真机复测**。
4. `lastMapInjection` 是工作区级（现在带 `sessionId`）；热度边车删节点不清条目，榜单可能留幽灵。
5. `router` / `inherit` / `scope` 随包但默认关闭，是实验代码，没有在真实宿主上验收。
6. 批量导入可部分提交，返回体带 `newNodesBeforeFailure` 与 `retryHint`，重试幂等。
7. 面板卡片没有渲染层测试（仓库禁止新增 UI 断言）；本轮在真实宿主里人工+Playwright 目检过一次。
