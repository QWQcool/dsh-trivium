# dsh-trivium 0.9.1

0.9.1 交付按名称查找实体、按需任务记忆包、文档依据和本机交接。内核继续固定 `triviumdb@0.9.1`。功能基线是 `11ee0aa`。

## 新增

- 实体范围面板和 `ctx_find` 支持工作区内的名称和别名查找。多个命中时可明确选择实体 ID，快照使用捕获时的名称。`ctx_find` 指定实体时可取紧凑记忆包，同一会话可按游标只取变化。[接口和参数](read-api.md#按需任务记忆091)
- 「上下文 → 文档依据」支持选择 Markdown 或 UTF-8 文本，也可粘贴原文。查找短片段后可关联到事实，按修订对照原文并标出受影响的引用。[文档依据接口](read-api.md#文档依据接口091)
- 「运行记录 → 待补写」显示同正文的已有事实，支持不采纳并保留来源，处理记录可分页查看。
- 本机 Super Agent 交接支持显式项目与工单作用域、可离线提交的中央收件箱和持久回执。交接候选也可在待补写面板核对。[协议与示例](handoff-protocol.md)

## 改进

- 修复已知英文和部分中英跨语言词面漏召回。相同范围的词面和地图读取可复用进程内缓存，数据、关系、到期状态或来源变化时重新判定。
- 后台抽取先持久保存原窗口，超时后保留可恢复内容。旧记忆的改写缺少独立依据时保留待核对。复核和交接重试可复用已有落盘结果，同一已记录来源的同一事实由不同 Worker 转交时只写一次，各自保留回执。
- 默认设置路径随 `DSH_HOME` 隔离，设置、Git 旁路和使用记录替换失败时保留原文件。状态页区分库损坏、占用和暂不可读，可继续切换其他工作区。
- 文档来源和关联分别分页。按事实或来源限定读取范围，旧引用仍可复核。[交付和相关测试](CURRENT-STATE.md)

## 删除与移除

- 移除复核记录只保留最近 1024 条的截断、替换失败后删除原设置或旁路文件的路径，以及证据查询对全库正文的预扫描。
- 移除等待超时后仍能写入的迟到模型结果和将记忆工具回显当作独立来源的路径。四个公开工具、旧事实和历史评测夹具均保留。

## 升级与数据保留

1. 完全退出桌面程序（包括托盘），或停止 Web 宿主。在原 profile 直接替换插件。0.8.9 的卸载脚本可能删除记忆，尤其需要直接替换。
2. 桌面运行 `dsh plugin --profile desktop add dsh-trivium@0.9.1 --ignore-scripts`。Web 将 `--profile desktop` 换成 `--profile web`。

   Windows 若找不到 `dsh`，可用桌面版附带的命令。

   ```powershell
   & "$env:LOCALAPPDATA\Programs\DeepSeek Harness\resources\runtime\cli\bin\dsh.cmd" plugin --profile desktop add dsh-trivium@0.9.1 --ignore-scripts
   ```

3. 重启原宿主，再打开原工作区。保留完整 `.dsh`，包括数据库及附属文件、文档依据、快照、待补写、复核历史和中央收件箱。0.9.0 与 0.9.1 都使用 TDB 0.9.1，升级无需迁移数据库格式。从使用 TDB 0.9.0 的旧插件升级前，请保留完整旧文件组。 [旧版升级与回退](release-0.9.0.md#升级与数据保留)

设置路径依次为显式 `DSH_TRIVIUM_SETTINGS`、`$DSH_HOME/trivium.json` 和 `~/.dsh/trivium.json`。在自定义 `DSH_HOME` 下需要沿用旧配置时，可显式指向旧设置文件。

回到插件 0.9.0 时，退出宿主后使用相同的直接替换命令并指定 `@0.9.0`。保留原 `.dsh` 和配置文件。旧面板可查看原待补写数据，完整复核历史和交接记录在换回 0.9.1 后可查看。自定义 `DSH_HOME` 下可用 `DSH_TRIVIUM_SETTINGS` 指向对应的 `trivium.json`。

## 验收与范围

- 沿用设定和证据读取、名称查找、本机交接的专项测试及隔离 Web 结果。两次相同自动交接共用一个节点，各有回执。确认和补充依据共用相同事实节点，不采纳只留复核记录。[当前验证状态](CURRENT-STATE.md)
- 多轮对照中三组回答均为 11/12，紧凑包加游标的输入 token 比常规召回少 20.3%。结果限于该题集。引用、实际用量和延迟按组报告。[多轮对照](reviews/MEMORY-MULTITURN-2026-11-19.md)
- 文档依据限定已选来源，暂不扫描文件目录。中央交接由可信本机宿主管理，使用显式配置。输入的实体范围、预算和游标均按需启用。
