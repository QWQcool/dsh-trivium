# Trivium 设置页重设计交接

日期：2026-11-03。审查基线 `f2234a6`，package `0.8.3`；本地领先远端 6 个提交。本次只交付设计，未修改 `lib/`、默认开关、数据库、模型工具或发布版本。

**给实现 AI 的入口：先用浏览器打开 [HTML 交互设计稿](SETTINGS-REDESIGN-0.8.3.html)，再点击右上角「设计与实现说明」。** 不要只看截图实现。HTML 自包含、无依赖、无需服务端；所有操作只改变演示内存，不连接真实 DSH 或记忆库。

## 要解决的问题

当前设置页把记忆列表、每轮投递、试算、完整性检查、恢复状态、导入导出、配置与更新放在长页面中。低频维护项和常用查找没有清晰层级；名词还混有注入、召回、短地图等实现概念。

新设计保留一个宿主插件入口，内部拆为四页：

| 页面 | 主要任务 | 不再常驻的内容 |
|---|---|---|
| **记忆库（默认）** | 搜索、核对、编辑记忆，查看来源与历史 | 全局配置、运行诊断、版本更新 |
| **上下文** | 区分「实际发送」和「只读试算」 | 写入变化、故障恢复、数据维护 |
| **运行记录** | 排查写入、恢复、卡住、空回答、更正和记录缺口 | 常用记忆编辑、全部配置 |
| **设置** | 记忆行为、显示、数据、向量、协作、关于 | 成片展开的技术说明和调试信息 |

全局「查找设置或操作」可用 Ctrl/Cmd+K 打开，输入“芯片”“恢复”“导入”等直接定位，不要求用户预先理解分类。

## 设计边界与现有能力

1. **查看工作区不等于切换对话工作区。** 条目、导入、诊断请求必须带当前视图的 cwd，并隔离迟到响应；配置开关当前是全局设置，不可因面板选库而伪装成按库设置。
2. **已实现功能要搬家，不能删失。** 归档/删除/合并、确认替代/撤销替代、关联过滤、独立的过期/已替代/归档筛选、完整来源及历史、JSON/Markdown、外部文件选择、Git、向量回填、更新检查均要保留。部分复杂流程在原型中仅展示入口和说明，实施时复用原有完整行为。
3. **SuperAgent 当前只有范围接口的 stage 0。** `lib/store.js` 的 `resolveScope` 只实现 workspace；parent/inherit 明确拒绝执行。设计中只预留「协作与范围」说明页，不出现能启用共享或继承的假开关，不创建 Worker 管理台。
4. **新字段状态以真实 API 为准。** 发布后的 `lastMapInjection`、`stuck`、`recovered` 可在上下文/运行记录呈现；没有观测值就显示未知，不把空数据当成功。
5. **“新增记忆”是拟增强入口。** 当前 `POST /chips` 只接受文本并推断类型；没有设计稿所用的名称/类型/期限完整创建接口。实现方应先确定严格创建契约并补验证；不可宣称已有 `POST /nodes`，也不可借创建操作偷偷开启芯片或自动钉选。若暂不扩接口，第一阶段复用纯文本新增流程，并明确字段差异。
6. **偏好导出仍为 CLI 能力。** 当前没有与 `dsh-trivium-prefs` 对应的设置页写入 API；本稿仅放高级说明。不要做一个无法落地的网页保存按钮。
7. **预算及替换行为不是设计稿算法。** 不改变现有 300/400 估算 token、模型工具、默认开关、替代判据、写入过滤或版本链保护。代码与历史文档冲突时按当前真实实现复核，不照抄旧的“12秒/3条”文案。

## 核心实现约束

- `lib/client.js` 使用宿主 ModuleLoader / React / UI primitives。HTML 的模拟宿主侧栏、顶部演示工具条及固定 fixture **不进入生产**；颜色和字号映射到宿主主题，而非强制覆盖宿主全局样式。
- 1440/1280px 列表+详情并排；900–1179px 切为列表+详情弹窗，保留真实宿主侧栏空间。小于900px只是设计探索，不宣称支持现有宿主手机布局。
- 标签和按钮保持中文语义一致，正式实现同步英文；原型的 English 选择仅模拟保存，不提供完整翻译。
- 即时保存项需要就地保存中/成功/失败回滚；向量配置独立提交，并处理未保存导航。失败不能统一显示“已保存”。
- 详情编辑遇到409保留草稿和对象身份；版本链正文保持只读。归档、删除、合并、撤销分别遵守已有服务端保护，不只靠隐藏按钮。
- JSON导入采用现有服务端预览及再次提交校验，取消不写入。外部文件显式逐项选择；不能用空 ids 意味着用户同意全部导入。
- Git删除当前涉及全部已登记工作区，确认框应列目标；生成覆盖当前同路径文件。任何改为单库接口的行为应另列变更，不能在重设计中暗改。
- 来源缺失显示未记录；没有原文回读/跳转能力就不造链接。决策替代链与最多3条合并历史要分别解释。
- 恢复超时不等于失败；进程内观测、持久审计缺口和裁剪范围分别呈现；不得伪造完整历史或给出未实现的“立即修复”按钮。
- 弹窗需焦点陷阱、Escape关闭/草稿拦截和关闭后焦点归还；详情页签支持方向键，所有主操作支持键盘。

## 建议实施与验收顺序

1. 导航与路由拆分；既有功能逐项映射，先保证没有入口丢失。
2. 记忆列表与详情；新增入口先确认创建契约，保留版本/权限/并发保护。
3. 上下文与运行记录；真实送达、试算、写入结果、恢复四者分清。
4. 设置分类与命令搜索；区分配置作用域和按库操作，保持当前默认值。
5. 在可证明隔离的环境验收900/1280/1440px、浅深色、中英文、键盘、长文本、空库、读失败、409、锁占用、导入失败。**不得启动或修改用户默认工作区做试验**；本稿的浏览器验证不能代替真实宿主验收。
