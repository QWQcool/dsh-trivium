# 设置页四页化：实施记录（第一阶段）

日期：2026-11-03。基线 `f2234a6`（0.8.3）。对应设计稿见
`docs/design/SETTINGS-REDESIGN-0.8.3.html` 与 `SETTINGS-REDESIGN-HANDOFF.md`。

**前置约束**：本轮功能开发冻结，只做前端信息架构重构；`lib/` 下的服务端逻辑、默认开关、
数据库、模型工具、版本号全部未动（本阶段唯一改动的产品文件是 `lib/client.js`）。

## 做了什么

原来的设置卡是"一个长页面 + 列表/召回两个标签"。宿主只提供一个 `settings.section` 入口，
所以拆分发生在卡片内部：

| 页面 | 现在装什么 | 来源（原位置） |
|---|---|---|
| **记忆库**（默认） | 工作区选择、搜索/类型/过期/已替代筛选、条目列表与展开编辑、归档/删除/合并、更正与撤销 | 原「列表」标签 |
| **上下文** | 「这一轮实际发送」（真实送达记录 + 预算条）、只读试算（查询 → 计划/候选/被丢弃/将发送文本） | 原「召回」标签的前半 |
| **运行记录** | 运行诊断（新增）、维护检查/版本链完整性、更正队列、恢复状态、记忆变化、最近召回轨迹 | 原「召回」标签的后半 |
| **设置** | 维护（导出 JSON/Markdown、导入）、检查更新、配置（抽取/芯片/会话层/Git 旁路）、界面语言、注入策略三选一、外部记忆导入、embedding | 原来常驻在长页面底部的卡片 |

新增「运行诊断」卡：把 `status.lastExtract`、`status.stuck`、`status.recovered`、
`status.lastMapInjection` 四行放在运行记录页顶部；**没有观测值就显示"没有记录"**，
不把空数据渲染成 0 或"成功"。

导航：`role=tablist` + 四个 `role=tab` 按钮，`aria-selected` / 漫游 `tabIndex`，
方向键、Home/End 可用；页面状态只存在于 React state，不写 URL、不写本地存储、不触发请求。

按需加载：`loadTraces / loadCorrections / loadTurn / loadChanges` 从"召回标签打开时"
改为"上下文或运行记录页打开时"——仍然是按需，不是常驻轮询。

## 没做什么（下一阶段）

1. **Ctrl/Cmd+K 命令面板**：设计稿的核心入口，尚未实现（对应实施顺序第 4 步）。
2. **列表 + 详情并排**：详情目前仍是列表内展开；设计稿的 1440/1280 双栏与 900–1179 弹窗未做。
3. **视觉语言**：未引入设计稿的配色/字号/间距变量，仍用宿主主题与现有 `ui.*` 样式。
4. **设置页分组标题**（记忆行为 / 显示 / 数据 / 向量 / 关于）与卡片重排。
5. **新增记忆的严格创建契约**：`POST /chips` 只接受文本，本阶段未改接口，也未新增按钮。
6. **偏好导入导出**（CLI 能力）没有网页保存入口，按设计稿只保留说明。

## 测试与验收

```
node scripts/smoke-p78.mjs   → 35/35（新增，结构级）
node scripts/run-all.mjs     → 79/79（改前 78/78）
```

`p78` 用 vm 加载真实 `lib/client.js`，用最小 hooks 运行时 + 保留树结构的 JSX stub 渲染组件，
断言：四个页签存在且默认选中记忆库；每页只显示自己的卡片；跨四页汇总后原长页的每个分区
（维护/检查更新/配置设置/界面语言/外部记忆/记忆变化/运行诊断/这一轮实际发送）仍可达；
方向键换页；回到记忆库列表仍在。它**不替代**真宿主验收。

三个既有客户端测试因信息架构变化做了映射（不是放宽断言）：

| 测试 | 改动 | 理由 |
|---|---|---|
| `p18` | 源码断言从 `tabList/tabRecall` 改为 `pageMemory/pageContext/pageRuns/pageSettings`；按需加载断言从 `if (tab === "recall")` 改为 `if (page === "context" \|\| page === "runs")` | 断言意图（两类内容分开、按需拉取）不变，只是导航改名 |
| `p24` | 点击「Recall check」改为点击「Activity」 | 更正队列属于诊断，移到运行记录页 |
| `p26` | 新增 `openPage(p, key)` 助手；原先 `tabs()[1]`（召回）按内容分别映射到 `runs`（恢复/变化/更正）与 `context`（这一轮实际发送）；设置保存测试先进入设置页，并排除页签按钮 | 页面拆分后"进哪个页"变了，但每个用例验证的行为不变 |

`p76` 顺带修了一个**测试自身的跨日缺陷**：先 `utimesSync` 再 `writeFileSync` 会把 mtime 重置成当前时间，
于是"旧锁"在跨天后不再旧。改为先写后打时间戳。

## 已知风险

1. **真宿主未验证**：只在 vm 渲染层验证过；宿主里页签的间距、滚动与 `ui.tab` 样式未实机确认。
2. **页面切换保留状态**：草稿、展开的条目、试算结果都留在 state 里，切页不丢——这与设计稿一致，
   但如果将来把页面写进 URL，需要重新决定是否清空详情。
3. **`CURRENT-STATE.md` 已过期**：它仍写着 `run-all 73/73` 与"0.8.3 之后只有文档提交"。
   本轮结束后是 79/79 且多出 6 个提交，需要单独一次文档对齐。
