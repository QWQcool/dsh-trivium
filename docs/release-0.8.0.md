# dsh-trivium 0.8.0

状态：**已发布**。npm `latest=0.8.0`，GitHub `main` 与 `v0.8.0` 已更新。北京时间 **2026-10-29 11:55:18** 发布；包含此前未发布的 B 批界面功能，以及 C 批复核和成本修复。

## 变化

- 设置页优先展示记忆操作，增加工作区选择、未保存草稿保护、统一操作回执和只读导入预览；确认提交校验库指纹，变化时返回 409。召回检查区区分实际投递、查询试算和维护信息。
- 未过期的精确名称命中优先保留；禁止模型通过 ctx_remember 绕过版本关系确认；损坏的循环、分叉、过长链和无效端点不被投影为当前事实。
- 抽取改为同批单次在途，保留抽取期间新增消息；失败可以重试，冷却结束能继续处理。纯致谢不调用模型；修复多字母方案名被截成单字母。
- 模型摘要不再携带工作区存储路径，保留业务边；完整读取使用紧凑 JSON，正文和字段不截断。精简注入说明，预算及默认开关不变。
- C3 使用完整同源材料、隔离场景库和结构化判据，保留原始轨迹与费用日志。没有声称与纯文本等效或图记忆必然更优。

四工具、数据格式、默认开关、依赖 pin、DIM=1536 不变。没有新增服务或默认 embedding。抽取提示词压缩经小样本检查后撤回，生产保留原提示词；有效对话修复漏处理后可能增加调用，不能承诺统一费用降幅。

## 验证与限制

本轮离线回归 35/35；最终 tarball 干净安装、真实 DSH rc.4 peers 的 13 项验证及两个维护 CLI 帮助命令通过，38 个安装文件与源码规范化换行后逐一相等。隔离实际 Web 3098 HTTP 检查通过：装载/隔离设置、导入预览只读、成功提交、过期指纹 409、不重复写、列表及轮账本。没有运行用户真实工作区，没有新一轮完整桌面/UI 手工验收。

真实模型请求 152 次，按官方高峰价与 usage 估算 ¥0.09970888，未超过 15 元上限；不是实际账单。判据、公平性、成本结果及局限见 [完整报告](next-memory/COST-QUALITY-RESULTS.md)。新调度、成本与质量仍待独立验收；已发布状态不等于独立验收通过。

C4 对手验证留在发布之后。50k 本机负载、旧 S09 默认自动召回换述不足、规则/模型的近义候选重复、每工作区单个 pending 文件的多会话持久恢复仍有局限。本轮没有冒充解决这些问题。

