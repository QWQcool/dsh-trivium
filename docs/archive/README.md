# 归档（历史文档）

这里放的是**已经结束的**工作材料：2026-10 至 0.8.6 期间的执行计划、阶段结果、审计、失败记录与交接稿。
2026-11-11 从 `docs/` 与 `docs/next-memory/` 顶层整体移入（`git mv`，历史可查），目的是把日常维护面收窄到几份"活文档"。

## 怎么读

- **按日期读，不要按语气读。** 里面的"当前""未发布""下一步"只描述写它那一天，不是今天的指令。
- **结论可能已被推翻。** 例如 R1/R2、A5/A10 的基线、D1/D2 的对照实验，后续复审都做过更正；以 [CURRENT-STATE](../next-memory/CURRENT-STATE.md) 与对应发布说明为准。
- **这里的链接不保证可用。** 归档内部互相引用的路径基本保留，指向活文档的相对路径可能已经失效；需要时按文件名在仓库里搜。
