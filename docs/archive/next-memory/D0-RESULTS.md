## 5. 未覆盖（本轮新增 + 继承）

1. **对手工具面未跑**：`dsh-memory` 的 27 个工具、`goodmemory` 无工具，与本轮 4 工具臂不可比；
   工具臂只证明「我方摘要在本语料够用」，不能反推「工具无用」。
2. **超出摘要容量的语料未测**：单条 >200 字且关键信息在**中部**时，尾部保底仍会丢；这类事实需要 `ctx_read`。
3. **goodmemory S05/S07 为空的原因未定位**（只确认是其桥自身行为）。
4. **真实宿主端到端未跑**：仍是「真实插件 apply + 真实 pre-step + 宿主 peer 0.2.1-rc.4」，无 UI/审批/压缩/多轮。
5. **多轮与压缩后未测**：所有格都是单轮；会话变长后地图与轮内去重的影响未知。
6. **n=3、两模型**，方差与模型差异未做统计检验；`plain-all` 不设预算上限（它是上界臂）。
7. **嵌入通道关闭**：本轮 `semantic=off`，检索是词法+关系+锚点。
