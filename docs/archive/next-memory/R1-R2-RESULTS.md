## 实现

### R1：不靠漏记降低成本

- 门控从“前缀 + 长度 + 专名猜测”收窄为**整句无内容短语白名单**；必须检查整个窗口。中文姓名、金额、端口、次数、否定、指代、助手新事实均保留；任何工具证据保留。无法证明为空时交给原有抽取。
- 新反例先跑：p38 冻结同一份最终回归，在基线 93faf37 上为 **8/25**；修后 **25/25**。覆盖真实 distill → 合成库落盘 → 消费窗口，以及失败时 pending 保留。模型部分使用计数桩，不冒充真实抽取质量。
- 芯片、历史芯片统一采用头尾摘要；历史芯片仍保留原节点，不自动切换到后继。
- 摘要和事实身份分开：新增仅在内存中传递的全文 `bodyKey`，正文中部变化也能被追踪；候选、投影、投递账本、到期和变更通知一致使用。只改 aliases 不再误发更正；真实正文/期限变化仍发，重复通知按原语义去重。
- 未改变默认开关、60 秒静默 / 12 条消息 / 5 分钟冷却、300/400 预算、DIM=1536、四工具参数或持久数据格式。

### R2：实验隔离、计费和判据

- C4-R2 所有库、设置、会话身份按 **arm/rep/scenario** 分开；拒绝复用同一 cell。开库前检查合成路径，开库后检查空库，种植后验证数量与正文 hash。反序执行用于检查顺序污染。
- 所有适配器都收到包含名称的正文，避免只有我方得到独立 `name` 字段、对手只得到不含名称的正文。这个协议变化已记录，旧质量分数不能直接套用。
- 我方在 C4 中捕获实际短地图；D1-R2 模拟会持久化注入历史，模拟压缩时发 compaction/end 并重新捕获地图。**这仍是模拟器，不能当真实宿主闭环。**
- 共用请求账本：请求前保存最高价预留、完整请求和逐次 usage；HTTP 错误、超时、缺失 usage、未知模型价格都会锁止后续请求。未知费用保留预留额度，不继续试到预算耗尽。
- 计费重算只遍历 calls；622 次请求、峰价归一化 **¥0.35791996**、谷价归一化 **¥0.17895998**。缺少请求账本或未知用量明确标记未完成，不把格数当调用数。
- D3 重放按实际保留的请求逐条相加，batch 使用自己的实测 usage；不再把三会话总额重复乘 3，也不拿混合平均单价代替有内容的请求。当前保守门控不会跳过 D2 中非平凡推进句，因此这批旧语料为 **15→15**，费用 **¥0.005369→¥0.005369**；不能继续宣称省 80%。
- D2-R2 走真实 distill 与独立临时库，保存原始回答、解析候选、过滤候选、每个窗口结果和最终库。评分只依据实际正文中的整条合成事实，检查主体/值/否定/时效，漏项、重复及额外内容均报告。quote/name 命中不能替代正文；无法精确判定的改写进入人工语义复核，**不把严格模板匹配称作自然语言准确率**。
- 新证据打包保留原始回答，拒绝覆盖不同的历史文件；增加真正只读的清单校验命令。
