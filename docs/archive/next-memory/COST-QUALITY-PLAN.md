# 评测与成本修复：预注册（2026-10-29）

基线：490a748；版本暂为 0.7.1。用户授权完成后发布新版本，C4 留到发布之后。

## 固定范围

- 不改默认开关、四个工具的参数、数据格式、DIM=1536；不接外部记忆服务。
- 保留 60 秒静默 / 12 条消息 / 5 分钟冷却，修复在途清空、失败去重和冷却饥饿；明确失败不自动无限重试。
- 注入只去除重复说明和工作区存储路径，保留事实、业务关系、版本/过期提示及 300/400 token 预算。完整 ctx_read 不截断。
- 所有库、设置和 DSH_HOME 使用临时合成目录。

## 评测门槛

1. 新判据以合成事实的结构化字段为金标，字段集合及值均检查；否定、缺项、泛泛提到“基线”、额外矛盾字段和非 JSON 都不能通过。原来的字符串命中率停止作为正确率引用。
2. 三臂：无记忆、完整纯文本、图记忆读工具。纯文本由同一合成库完整投影生成，包含同样的无关/历史材料；不再手挑答案。相同题目、系统指令、输出格式。每场景/臂/重复独立库。
3. 10 个场景、每格 3 次、单一模型、temperature=0；按重复轮换臂顺序。记录全部答案、工具循环、usage 和服务端 model。成功率只是本合成任务字段完成率，不能证明等效或泛化；这是流水线比较，不能归因于“图结构”本身。
4. 固定 deepseek-flash、关闭思考、每响应最多 600 tokens、工具最多 4 轮。采用 2026-10-29 官方高峰价作为保守估算：缓存输入 0.04 / 非缓存输入 2 / 输出 8 元每百万 tokens。实际账单未获取。
5. 整次真实模型实验总预算不超过 15 元，每个请求先保留按 UTF-8 字节及协议余量估算的输入上界和最大输出费用；网络失败或缺失 usage 保留全部预留额度，不无界重试。落盘费用日志后才发请求。
6. 先通过离线判据反例、场景装载与隔离断言，再运行真实模型。不根据结果修改金标再跑出漂亮数字。

## 成本证据与发布门槛

比较同一输入序列的实际调度调用次数及实际构造的提示词/注入文本（本地 token 估算明确标注），同时检查事实与更正没有丢失。此前“68%”来自调度模拟，不能当作真实账户节省。

全量离线回归、评测可审计产物、干净 tarball 安装与真实 DSH peer 装载通过后再发布。发布后核验 registry 的版本、latest、integrity 和 Git 远端。界面手工验收及真实长期使用节省如未覆盖，单独列出。

补充抽取提示词检查（发请求前登记）：E01 否定偏好、E02 日期不是失效期、E03 重复实体、E04 同轮工具失败后成功、E05 一次性修改、E06 纯致谢；旧/新提示词各一次，400 输出上限与生产一致。保存原始候选及最终落库内容，由维护者逐条检查语义，不把关键词匹配包装成自动正确率。独立预算上限 1 元；与主实验合计仍须小于 15 元。该小样本检查不能证明抽取质量等效。
