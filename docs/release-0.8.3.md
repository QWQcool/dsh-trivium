# dsh-trivium 0.8.3

状态：**已发布**（npm `latest` + git tag `v0.8.3` + GitHub Release，2026-11-02）。
tarball shasum `7406c132433941a32ca9e0698a05bde883b2136c`，44 个文件 / 213.7 kB。

这一版是**正确性补丁**，共 24 个提交。核心是四件事：改口不再覆盖旧决策、来源与变更可追溯、
幻觉日期与可疑空回答有据可查、同一工作区只允许一个写者。

## 修复（会静默丢事实或给出过期答案的）

| 缺陷 | 修前 | 修后 |
|---|---|---|
| 改口被"合并"吞掉 | 「不用 A 了，改 B」合并进旧节点，旧正文被覆盖，`supersededCount=0`，无替代边 | 替换场景新增节点 + 建 `supersedes` 边，旧正文保留（并在 `payload.history` 留最近 3 版） |
| 会话启动先建图、后重放 | 15 次真机里 3 次新会话拿到 `decisions=0`，答"没有记录" | 先 await 重放（上限 8 秒）再建图；超时继续启动并记 `replay-timeout` |
| 可疑空候选 | 模型对含决策的窗口回 `{"candidates":[]}`，窗口被消费，事实消失 | 规则层无产出且窗口明显含决策时**再问一次**（最多一次），仍空则记 `emptySuspicious` |
| 幻觉绝对日期 | `On 2026-04-06`（会话发生在 10-30）原样入库 | 日期必须能被本轮原文或唯一相对表达（按该轮时间戳）解释，否则删除并上报 |
| 删除日期留残句 | `2026-07-13 起采用…` → `起采用…` | 连接词随日期一起删除 |
| 同一写入重复落库 | 重放 + 轮末各写一条措辞不同的副本 | 按"同一事件 + 同名"折叠；同义改写不再写成两条 |
| 第二个写者直接崩 | 两个宿主进程同工作区，后者 `openWorkspaceDb` 抛错、进程退出 1 | 写锁在**开库之前**获取；失败方不开库、保留 pending、记 `lock-busy`，下一事件继续 |
| 凭据经诊断接口回显 | 日期清洗的 `adjusted.preview` 携带合成凭据片段进 `/status` | 凭据闸门前置；预览再过闸，不通过写 `<redacted>` |

## 新增

- **来源贯穿**：节点记录宿主真实事件定位（`seq / messageId / at / role / quoteMatch`），
  缺失字段为 `null` + `recorded:false`，不用节点 id 或当天日期伪造；`hostText` 恒为 `unavailable`（无回读接口）。
- **变更记录**：`GET /api/dsh-trivium/changes`，每工作区最多 200 条，落盘前脱敏，`opId` 幂等，裁剪有明确标记；
  面板「记忆变化」区块显示写入/合并/替代/拒绝/日期调整/恢复超时/写锁占用。
- **合并历史**：`payload.history` 保留被覆盖的正文（上限 3、倒序、旧凭据正文 `<redacted>`），
  节点列表直接展示"合并前的正文"。
- **空回答可见**：`status.emptyAnswer` 记录"这一轮没有任何文本"的轮次。

## 行为变化（升级前请读）

1. **改口不再覆盖旧节点**：替换场景会新增节点并建边，旧库里同一个决策的多次改写将呈现为链；
   已有历史**不会**被自动重建，升级前的覆盖无法找回。
2. **短地图只列当前决策**：已被替代的决策不再出现在短地图，`ctx_read` 仍可读到。
3. **会话启动最多多等 8 秒**（pending 重放预算）；超时后台继续，pending 保留。
4. **同一工作区只允许一个写者**：并发时后来者跳过本轮抽取并记录 `lock-busy`，不排队、不崩溃。
   该锁只覆盖自动抽取写入；`ctx_remember` 与文件导入仍可能撞"已被打开"错误。
5. **可疑空候选可能多花一次模型调用**（仅限"窗口明显含决策且规则层无产出"）。

## 已知限制（请勿对外宣称"不会误判"）

1. **自动替代是措辞启发式**：经四轮独立复验，仍未覆盖所有说法；已登记的守卫包括问句（含句中问句）、
   引号/转述、未批准、撤回（含否定式）、讨论/假设、方向（弃用 vs 改用）、候选顺序。
   **未预料到的措辞仍可能误退休**，这是本版接受的风险；彻底的解法是把替代改为"提案 + 用户确认"，
   已写入 `docs/next-memory/SUPERSEDE-CONTRACT-OPTIONS.md`（P / P′），本版未实现。
2. **完全无替换措辞的改口不退休**（例："还是回到最早的方案吧"），只上报 `no-replacement-wording`。
3. **同义改写**在改名/改措辞时仍可能留两条节点（精确同文与同名会折叠）。
4. **日期**只识别 `YYYY-M-D` 三种写法；不认美式 `04/06/2026`、英文月份、中文数字日期；
   过去 7 天以外的相对表达不解析。
5. `emptyAnswer` 是进程内状态，只对仍在运行的宿主有意义；HTTP 级自动回归未覆盖（仅脚本验证）。
