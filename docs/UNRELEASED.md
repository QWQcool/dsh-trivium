# 开发中变更

当前 npm 发布基线是插件 `0.9.1`，内核 `triviumdb@0.9.1`。已交付的新增、改进、移除和回退步骤见双语发布说明。[中文](release-0.9.1.md) · [English](release-0.9.1.en.md)

## 新增

- 源码固定 TDB 0.9.2，提供工作区升级命令 `dsh-trivium-upgrade`。可预检、整组切换、查询进度和回退。旧库、引用和交接回执保留，回退时新版写入另行保留。 [升级与回退步骤](kernel-upgrade.md)

## 改进

- 记忆面板能区分旧格式和升级中断。新版宿主在切换未完成时阻止打开工作区写入。
- 自动召回和实体任务记忆包随已选事实提供匹配的已存别名，减少跨语言追问中证据命中后仍回答 `unknown` 的情况。
- 全量记忆包以 JSON 数字呈现事实和路径 ID，并标明引用取事实行的 `id`。面板接口的结构化 ID 继续使用字符串。 [严格引用复验](reviews/FOLLOWUP-DOCUMENT-REVIEW-2026-11-19.md#全量包数字引用复验)
- 文档依据按事实显示修订提醒。仅移位且引用整行和标题路径一致时免于复核，所有旧引用继续保留。 [专项验收](reviews/FOLLOWUP-DOCUMENT-REVIEW-2026-11-19.md)

## 移除

无。

验收条件和顺序见 [路线图](ROADMAP.md#插件-092-的开发范围)。
