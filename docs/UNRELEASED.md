# 开发中变更

当前 npm 发布基线为 `dsh-trivium@0.9.3`，内核为 `triviumdb@0.9.3`。首次写入保护、双语检索、目录导入和交接读写分权已记入双语发布说明。 [中文](release-0.9.3.md) · [English](release-0.9.3.en.md)

后续新增、改进、移除与升级影响从 `v0.9.3` 起记录。 [当前状态](CURRENT-STATE.md) · [路线图](ROADMAP.md)

## 0.9.4 本地发布候选（尚未发布）

[中文候选说明](release-0.9.4.md) · [English](release-0.9.4.en.md)。候选仍使用相同内核；实际发布和正式版本状态另行核对。

- 任务记忆变更：按当前实体预览和显式记下基线，重开后仍可比较；不自动注入。 [使用和接口](read-api.md#任务记忆变更)
- 文档证据：按明确的已保存来源和修订检索原文，合并相同引用的展示但保留每个事实的引用和复核状态。 [使用和接口](read-api.md#在选定文档来源内查找原文)
- 读取边界：孤立实体扫描取满 1,000 行会拒绝；实时 TQL 在上限恰好返回 1,000 行时可保守标记截断，响应字节预算重试的截断仍标明原因。
