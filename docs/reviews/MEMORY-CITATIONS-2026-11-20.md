# 多轮与引用稳定性检查（2026-11-20）

对象：`dsh-trivium@0.9.2` 的记忆包构建与引用格式。上一轮多轮对照只有 3 组 × 12 题；本轮把题集扩到 **32 个用例 / 35 个问题**（开发 24、留出 11），并把"引用必须是数字 id、禁止证据不得进入"变成可重复的离线检查。

**本轮没有调用模型**，因此最终回答正确率仍未测；测的是"模型能看到什么"和"引用格式对不对"。

## 1. 方法

- 题集：`scripts/fixtures/memory-citations-v1.json`（冻结于 2026-11-20，32 用例；6 类：稳定事实、已确认替代、冲突、无答案、跨语言、范围隔离）。
- 运行：`node scripts/memory-citations-check.mjs --strict --out docs/reviews/MEMORY-CITATIONS-2026-11-20.json`
- 每题：写入合成库（实体 + 一跳事实；`supersedes` 用真实 `revisions.supersede` 生效），调用真实 `searchEntity({packTokens:300})` 构建记忆包，检查：
  1. 相关 id 是否都在包里；
  2. 禁止 id（同名旁支 `#301`、外部工作区同 id、已替代的旧事实）是否**完全没有**出现；
  3. 包内事实是否以**未加引号的整数 id** 渲染（`"id":201`），且 token 估算不超预算。

## 2. 结果（35 题）

|---|---:|---:|---:|
| 构建出记忆包 | 35/35 | 24/24 | 11/11 |

`--strict` 的不变量（泄漏 0、预算不超、已入包的事实一定是数字 id）**通过**；"缺失"不作为失败，按真实召回缺口报告。

## 4. 与真实模型对照的关系

- 已有的真实多轮对照（三组 11/12、引用 11/12、9/12、12/12）仍然是回答质量的唯一证据；本轮**没有**新增模型调用。
- 本轮能证明：进入包的证据不会带旧值/旁支/外部库；引用数字格式在 35 题上零违规；预算零超限。
- 本轮不能证明：模型会不会正确使用这些 id，或在缺失证据时是否诚实拒答。

下一步若要闭合：用现有桥接跑这 35 题（预估 35 次调用，单轮 300 上下文 token、256 输出上限），记录回答、引用与逐次用量；不能把本轮的"格式通过"写成"回答正确"。
