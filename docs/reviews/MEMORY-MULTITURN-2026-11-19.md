# 实体名称与多轮记忆对照

2026-11-19。用 [固定题集](../../scripts/fixtures/memory-multiturn-v1.json) 的 4 个任务、每个 3 轮，对照三种方式。题集包含同一事实连续使用、已确认替代、冲突归档和从无答案到新增依据。[逐轮原始记录](MEMORY-MULTITURN-2026-11-19.json)

## 对照方法

每组各有独立的合成库及对话历史，使用相同种子、同一轮的写入变化、检索词、问题和 300 估算 token 的本轮证据预算。真实模型使用 `deepseek-flash`，每次最多 256 输出 token。上一轮实际发出的用户消息和真实助手回答继续送入同组第 2、3 轮，模型分别收到 0、2、4 条历史消息。各组请求顺序轮换。

| 方式 | 本轮发送的证据 |
|---|---|
| 常规召回 | 延续此前对照的 `recallPreview(mode: 'auto')`，发送现有词面加一跳路径选出的完整上下文。部署默认仍由用户配置控制。 |
| 显式记忆包 | 每轮用同一个实体别名调用 `searchEntity`，发送该实体的完整证据包。 |
| 紧凑包＋游标 | 用 `ctx_find` 的紧凑包读取实现，首轮发送初始包，随后继续使用同一查询及会话的游标。已更新的事实补入，移出的 ID 明示给模型。 |

每轮都要求模型仅使用当前证据集。全量块替换上一组事实，增量块只修改本组事实。评分分别检查状态与答案值、引用 ID 以及两者同时正确。引用须为当前可用且支持答案的唯一数字 ID；冲突题须引用两条，未知题须留空。保留格式不合格的原回复。检索与对话调用由评测器驱动，因此结果描述这三种指定检索策略的多轮对照。

## 复现

```powershell
node scripts/memory-eval-tasks.mjs --plan-only --out .tmp/NEW-task-plan.json
node scripts/memory-eval-tasks.mjs --out .tmp/NEW-task-live.json --bridge http://127.0.0.1:PORT/api/trivium-quality-eval --token-file LOCAL_FILE
```

生成仅用于评测的[回环桥接](MEMORY-QUALITY-2026-11-17.md#复现)。评测要求新的结果路径和未消耗请求的桥接实例，按冻结题集限制为 36 次。如请求中断，保留逐次状态和已经取得的结果。离线计划不访问模型。
