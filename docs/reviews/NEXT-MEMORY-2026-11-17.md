# 五项低成本记忆改进：统一实现与验证

日期：2026-11-17。全部五项实现后才启动测试；运行代码和语料哈希见[证据清单](../evidence/next-memory-2026-11-17/manifest.json)。功能仍在开发分支，未发布 npm、未安装正式桌面；用户此前已确认正式桌面为 0.9.0、原记忆可读。本轮没有操作真实记忆文件。

## 交付

1. 英文问句/所有格与有界中英词组；修复 L11/L12、F2/F5。复合标识符不拆成领域词，支持一次查询中的多个独立标识符；没有添加翻译模型或 embedding。
2. 候选「不采纳，保留记录」、相同正文提示、历史分页与回执重试。保留原候选、引用及来源；旧来源不能复活，新来源不会被旧的不采纳记录永久阻止。未合并、替换或删除旧事实。
3. 进程内派生缓存绑定句柄、变更版本、查询/范围/预算，正文、关系、事务、删除/ID 复用、到期和重开失效。已有投递账本单独控制注入，地图缓存前后返回相同内容。
4. [独立项目/工单交接协议](../handoff-protocol.md)：三 Worker 先持久提交，中央写者恢复后处理，URI 防止中断重试重复写入。图落盘和文件回执完成后才确认；不确定候选留中央复核。Router 关闭重开可正常重建句柄，模式启用后原始写操作不能绕过信封。
5. [文档依据接口及卡片](../read-api.md#开发中的文档依据接口)：真实 TDB put/resolve、UTF-8/CRLF 范围、修订校验和事务关联。更新/删除来源后保留旧引用和旧事实并提示复核；事实删除后 ID 复用不会继承原依据。编辑的原文先保存再允许关联。

## 兼容与后续边界

- 当前发布版本和正式桌面仍为 0.9.0；这五项的运行代码尚未交付到 npm。新版本号、发版和桌面更新需要单独执行；本轮没有改变部署。
- 此次首版曾把 dismiss 回执写进旧版不接收的字段；2026-11-18 已拆出完整历史并用正式 0.9.0 包复验读写。原记录和原记忆节点保留，操作见[开发中版本回退步骤](../UNRELEASED.md#回退到-npm-090--roll-back-to-npm-090)。

- 文档仅显式接收最多 64 KiB 文本，扫描有节点/字节上限；不做后台监听、自动导入或语义蕴含判断。命名图仍待评估；Git JSONL 不能完整还原文档证据。
- 未新增 Ollama、本地模型安装或远端 embedding 改进。后续优先真实任务与无答案覆盖，再决定默认召回和协议的宿主接入。
