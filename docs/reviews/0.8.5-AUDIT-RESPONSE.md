## F1 事实误合并 —— 已关闭（代码已改，反例可复跑）

评审给出的四组反例，逐条处理：

| 反例 | 原判定 | 现在 | 原因 |
|---|---|---|---|
| `1.5 秒` / `5.1 秒` | merge（相似度 1） | **insert**（`value-conflict`） | 归一化把小数点变成空格，两边都得到数字集合 {1,5} |
| `生产环境 npm` / `测试环境 pnpm` | merge（0.6） | **insert**（`below-threshold`） | 名字只共享「环境」这类通用词；现在通用词被过滤，且不同名字要求相似度 ≥0.8 |
| `十六天` / `六十天` | merge（0.71） | **insert**（`value-conflict`） | 中文数词被当作单字集合；现在按 `十六=16`、`六十=60` 解析 |
| `允许自动发布` / `不允许自动发布` | merge（子串短路） | **insert**（`negation`） | 子串规则在新守卫之前返回；现在否定/数值守卫先于子串规则执行 |

另外修掉两处：
- `don't` 的撇号在归一化时被删除，否定没识别 → 否定词先看原文；
- 短文本检查写在成功返回之后 → 移到前面，同名不同正文不再合并。

**更重要的决定：模糊合并默认关闭。** 阈值不可能靠手写样本校准，而合并是不可逆的（只有最多 3 条正文历史、
不建修订链）。现在 `identityMerge`（`~/.dsh/trivium.json`）缺键即为关，关掉时行为与 0.8.4 一致：
只有精确/子串匹配。`lib/identity.js` 的判定逻辑保留并被 20 条断言覆盖，将来开启时是显式选择。

## F3 地图差异超出预算 —— 已关闭

`buildMapDiff` 现在接受 `tokenBudget`，先按类别取行、再整体按预算裁剪，并返回 `omitted` 行数；

## F4 轮次键与预算 —— 未关闭

评审确认：无 host id 时按「历史条数 + 文本 hash」判轮，在定长窗口/历史被截断时会撞键，
