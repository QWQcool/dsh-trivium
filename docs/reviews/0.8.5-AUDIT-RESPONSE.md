## F2 快筛误判 0 —— 已关闭（按用户决定走「方案 B」）

改动：

1. **删掉全部形状规则**（shell 命令、slash 命令、路径、UNC 路径、URL、CJK 形状），连同它们产生的 0 分；
   现在只有四种零：空串、纯标点（无字母/数字/CJK）、`继续。`/`好的`/`ok` 这类填充列表、寒暄列表。
2. **混合窗口不再删除 0 分组**：只有整窗为 0 才消费窗口；否则 0 分组随其他分组一起进入抽取。
3. 每个窗口返回 `audit`（规则、原文前 120 字、是否丢弃），并写入 `workspaceStatus.lastScreen`、
   由 `GET /api/dsh-trivium/status` 暴露。**它只存在内存里、最多 3 条、重启即丢**；面板暂时没有为它加卡片。

为什么删而不是降级成 1：「形状像命令」从来不等于「没有事实」，而混合窗口已不再裁剪，
留着这些规则只能在**命令独占窗口**上省钱——实测 30 → 30（0.0%），换来一整类静默丢失。

剩余说明（不构成发布阻塞）：`audit` 仅在内存与当次窗口内，没有持久化与"重新处理"入口；
因为现在被丢弃的只有填充语，丢失的语义风险已降到最低。

## F3 地图差异超出预算 —— 已关闭

`buildMapDiff` 现在接受 `tokenBudget`，先按类别取行、再整体按预算裁剪，并返回 `omitted` 行数；

## F4 轮次键与预算 —— 已关闭

改法：键从 `txt:<历史条数>:<hash>` 换成**按会话单调递增的轮次计数** `t:<n>`：

- 用户消息变多，或条数不变但最后一条文本变了 → 新的一轮（`n+1`）；
- 条数变少（压缩/定长窗口截断）且最后一条文本相同 → **仍是同一轮**（不再把已花掉的预算重置）；
- 其余情况沿用上一个键。

有 host id 时仍然用 `uid:<id>`（最可靠）。代价写在模块注释里：**无 id 且定长窗口重复同一句话时，
永远看不出是新的一轮**，于是每轮预算不再重置——宁可少给上下文，也不静默超预算。

回归：`p86` **15/15**，含评审复现的两种失效（截断不换轮、定长同文不伪造新轮）、会话隔离，
以及第四轮要求的账本断言（空观察沿用 `t:1`、`beginTurn` 不重置已投递集合）。
