## 定向复核

在真实 Web 设置卡保存一份含 22 条关联的合成来源。编辑涉及原文改写、原句所在行的限定词变化、Markdown 小节改名及同句出现两次。复核提示只列出 5 条受影响的事实，其中一条在次页。其余 17 条引用的整行和所在小节一致，无需复核。用例含 CRLF 转 LF、UTF-8 字节移位和从旧链接补录的上下文。

比较卡可打开旧修订号和旧摘录。隔离宿主重开后，22 条原引用的修订号、字节范围与原文仍一致，事实正文保持原样。不同来源、不同工作区独立读取。旧链接无法核对历史上下文时仍待复核，事实已修改也继续提示。过期的保存版本返回 409，原修订可继续读取。

## 复现

1. 按[开发文档](../DEVELOPMENT.md)启动隔离 Web，依照题集写入合成实体、别名与 `about` 关系。每题限独立工作区。
2. 向 `recall-preview` 传 `{query: recallQuery ?? question, mode:"auto"}`，用 `text.recall` 与 `records[].id` 记录召回。向 `entity-search` 传题集的别名和 `query`，使用 `packTokens:300`、`limit:5` 和 `semantic:false`，用 `memoryPack.context` 与 `memoryPack.facts[].id` 记录全量包。
3. 保存形如 `{F01:{recall:{text,ids,embeddingCalls:0},pack:{text,ids,embeddingCalls:0}}}` 的 Web 捕获，每道题都填入实际文本和数字 ID。启动[本地评测桥接](MEMORY-QUALITY-2026-11-17.md#复现)，使用全新的输出文件。

```powershell
node scripts/memory-eval-tasks.mjs --followup-contexts WEB_CAPTURE.json --bridge http://127.0.0.1:PORT/api/trivium-quality-eval --token-file LOCAL_FILE --out NEW.json
```

文档可在合成工作区以两个不同小节和两条事实复现。保存后记录各自的字节引用，改写其中一处并在第二处前增补文本，核对 `reviewFactIds`、`status` 和旧 `reference`。旧引用失效、重复和同一行限定词改动均走人工复核。

## 全量包数字引用复验

全量包把每条证据渲染为一行 JSON。事实行的顶层 `id`、路径节点和边端点使用 JSON 数字，包头说明引用取事实行顶层 `id`。隔离 Web 面板展示的内容与发送给模型的包逐字一致。五题的事实 ID 与前版相同，别名说明继续保留。快照使用同一格式，过小预算仍整组省略冲突事实。面板接口的结构化事实和路径字段保留字符串 ID。[接口说明](../read-api.md#explicit-entity-search-unreleased-source)
