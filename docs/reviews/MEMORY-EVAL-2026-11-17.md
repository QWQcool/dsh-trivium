## 实现与边界

| 项目 | 本轮行为 |
|---|---|
| 评测器 | 错类型不算正确；同 ID 错正文不能靠 ID 命中得分；未改动的旧事实不算无来源新增。记忆包也独立核对正文、禁止 ID、实际上下文估算和 answerability |
| 证据文件 | `--out` 目标已存在即拒绝，最终写入使用独占创建；`--reps` 限 1–20 整数。记录冻结夹具、运行时代码及依赖哈希，恢复环境变量和 fetch；意外 fetch 请求会被拒绝并导致评测失败 |
| 无来源引入 | 自动模型候选须能在用户或成功工具的本轮来源中核对正文、引用、标识符/数值和否定；沿用原日期解析与原消息时间。来源不明的改写、主体错配和凭空值保留到 pending，不直接进入有效记忆 |
| 待核对候选 | 保存整理后的候选及原有窗口；下一次模型漏输出也不丢弃。来源未变时跳过启动重试，不阻塞后续独立窗口；来源补全后重新核对，即使模型返回空候选仍能写入原候选。日志预览不回显候选正文，面板明确标记尚未写入 |
| C4 | 词面候选把锚点自身放在匹配邻居之后；按相关分数排序，同分时较新记录优先。相同类型/名称但正文不同且都有效时返回 `MULTIPLE_CURRENT_FACTS`，不自动判定真伪、归档或添加替代边 |
| 任务记忆包 | 复用本次实体一跳范围和词面排序；显式 `packTokens: 1..2000`，默认 0 关闭。选择完整事实，包含实际路径、已有来源、记录时间、期限、复核标记和省略 ID；同名替代候选整组纳入或整组省略 |

这是一层保守的来源归因检查，不是完整语义蕴含证明；未知改写可能需要人工核对。手动工具写入和导入沿用显式写入语义。已有记忆不自动清理，历史重复不合并。候选及来源仍受已有字段长度和敏感值清理限制。

记忆包只作为面板/HTTP 的显式只读结果提供，未接入 `ctx_find`、自动注入或回答生成。预算是项目现有估算器对 `context` 字符串的估算；不计算整个 JSON，也不代表模型实际 token 或账单。无答案和歧义均不改成“已知答案”。完整协议见 [read-api](../read-api.md#explicit-entity-search-unreleased-source)。
