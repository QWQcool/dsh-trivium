# TDB 能力使用审查、查询面板范围与 embedding 验证

2026-11-12。审查基于 main@6d28ed5、已安装的 triviumdb 0.9.0 类型声明及隔离功能探测。以下是实现前审查，当时真实 embedding 调用 0 次，费用 ¥0。[功能探测记录](evidence-tdb-capabilities-2026-11-12/observations.json)

后续已完成 F-EMB-01/02 修复、16 条向量批量落盘、三类具名 live/snapshot 查询及面板，并用本地真实 GTE 向量验证。当前结论、原始 Ollama 加载失败和剩余项以[后续验收报告](LOCAL-EMBEDDING-READ-RESULTS-2026-11-12.md)为准；不要把下面的前置计划当成仍未开工的清单。

## 当前功能怎样使用 TDB

| 功能路径 | 当前能力与实现 | 优化或验收重点 |
|---|---|---|
| 记忆新增、编辑、关联 | 原生 payload、向量和边写入，插件维护来源、期限及确认契约 | 保持入口行为，先测实际多次落盘和整节点搬运。纯批新增可评估 batchInsert，含合并/更正的路径需保留现有写入结果语义。 |
| JSON 导入 | 已用 commitTransaction，写前有预检和指纹 | 已使用合适的原子提交能力。继续验证旧数据、关系约束和派生索引失败结果。 |
| 外部导入与芯片 | 已有同步延迟写入，批量归档/删除已合并 flush | 性能优化已在 6d28ed5，README 单列来源和测量范围。不能将批量归档收益扩展成所有写入的保证。 |
| ctx_find 与关键词退化 | searchHybrid 使用原生 BM25/向量候选，之后仍执行全库 keywordFallback | 优先把仅需 payload 的全量读取改为轻量候选，入选后再取关系。改用属性或 n-gram 索引前，保留标识符、中文、长尾和更正回归。 |
| 短地图、锚点与图扩展 | 已用原生按标签邻居和入边，保留兼容扫描路径 | 审查候选阶段是否搬运无用向量，核对退化触发条件。原生邻接可减少扫描，排序仍需保留当前版本、到期和 token 预算语义。 |
| 固定只读查询 | nodes 用原生字段投影，neighbors/orphans 用 reachableDetailed 和显式边预算 | 一跳查询可按实际访问量准入。当前统一 1000 节点门槛会拒绝大库中的极小邻域，需专项实验后调整实现。 |
| 在线自由 TQL | 借用宿主写句柄，用只读 Console 会话、原生准备与预算执行 | 保留引擎参数绑定、完整输入排序/聚合和明确错误。输出投影能减少宽行，异步 TQL/输出游标要以上游实际 API 为依据。 |
| 快照与 CLI | createSnapshot、校验后的 immutable 读取、独立进程和父进程超时 | 当前使用方式满足写句柄占用期间及停宿主后的读取。界面需显示捕获时间和代际，并保留损坏快照的错误。 |
| embedding 写入与回填 | updateVector 后每条直接 flush，回填逐条请求 | 先补 F-EMB-01/02，再评估有界向量写入批量。提交阶段要核对文本版本、节点存活及模型配置，复用现有写队列/工作区锁。 |
| 事实身份合并 | sameFact 仍为词面、类型、数值及否定守卫，缺省关闭身份合并 | 接上 embedding 后需独立评估向量去重。已有 26 对语料可作第一组正负例，不能把召回改善直接当作自动合并依据。 |
| 完整性与恢复 | 插件遍历修订链、URI 和业务约束，待补写/审计在外围文件中 | validateGraph、graphStats 可提供原生拓扑阶段，插件继续校验替代方向、来源和当前版本。修复动作需要保留业务契约。 |
| 会话画布、钉选、偏好与旁路导出 | 图中会话/业务节点配合外围设置和 JSON/JSONL 协议 | 导出只需要 payload/边时可避免向量搬运，保留钉选预算、偏好授权和导出范围。需要逐入口对照结果与持久性。 |
| Router、继承与调度 | 单写者和工作区锁，父库 readOnly 失败后已有 Router 读取回退 | 宿主集成继续验证句柄归属。live/snapshot 可作为复用读通道的候选，异步向量批检索与同步 TQL 分别评估主线程等待。 |

原生 API 名称已对照当前安装包。能力存在与适合当前路径是两个判断，工作预算、排序、截断和错误语义都需要按入口验收。

## 本轮探测得到的具体结论

### F-EMB-01　向量验证会静默转换维度和非数值

normalizeVector 将 2 维补成 1536 维、3072 维截成 1536 维，并将 NaN 等值替换成 0。固定库维度为 1536，适配策略应在评测前明确。优先采用原生 1536 维输出，其他维度需要单独验证适配方式。真实 provider 返回非有限值、全零或异常结构时应有明确的失败/降级结果。

embeddingReady 当前只表示启用且 URL 形状有效。测试记录应分别给出连接成功、向量验证成功、回填完成和检索效果。[适配器](../../lib/embed.js) · [固定维度](../../lib/schema.js)

### F-EMB-02　旧响应会覆盖新文本的向量

隔离本地桩创建同一节点的 old text 和 new text 两次请求。先完成新请求，向量前两项为 [0,1]。再完成旧请求，节点正文仍为 new text，向量却变为 [1,0]。

queueEmbed 回写前只检查有没有向量，没有核对当前文本是否仍对应请求。真实效果评估前应给提交增加文本版本/内容指纹、节点存活和模型配置校验，并验证乱序、删除、关闭与重试。TDB 负责写入传入向量，文本与向量的对应关系由插件保持。[向量提交路径](../../lib/store.js)

同一探测还显示，回填 4 个节点触发 4 次 flush，包含 workspace 元数据。后续应明确业务类型范围，再测批量请求与批量持久化的收益。

### 只读查询的两个面板前置契约

当前 nodes 是原始节点列表。本轮实测包含 workspace、archived、expired 和 superseded 条目。它符合当前接口形状，面板中的“当前事实”需要单独定义。建议复用现有业务类型、归档、期限和 current-head 规则，未确认的替代提案两边继续具有当前资格。[固定查询](../../lib/read-query.js)

带 snapshotId 的查询目前要求 tql，发送 kind=nodes 返回 QUERY_INVALID。因此面板的三个固定查询需要在 live 与 snapshot 中复用同一选择逻辑或经过验证的模板，并统一投影和错误。旧快照的“当前”还要明确是按捕获时刻还是查看时刻计算期限。[快照请求验证](../../lib/read-snapshots.js)

### 原生局部访问有机会减少保守拒绝

在已关闭的 5000 节点合成库上，用 readOnly 句柄调用有界 reachableDetailed 得到 0 个业务邻居且没有截断，而现有 neighbors 固定查询在入口返回 422 READ_QUERY_WORK_LIMIT。优先评估按实际访问节点/边数约束的一跳实现，保留结果上限与超界拒绝。

indexedLookup 对选择性过滤返回了 1 个正确结果。对有大量匹配的 type/status 过滤设置 6，直接得到 TDB_QUERY_BUDGET。maxResults 不能直接当作可截断分页。该探测验证能力与边界，单次耗时不构成性能收益结论。

全库孤立实体判定仍需要完整覆盖或明确的分批协议。快照也有原生预算，切换来源本身不能保证大库扫描成功。

## 只读查询面板的首期范围

建议放在现有「上下文」页的只读诊断区，复用已有四页导航、条目与详情组件。先完成上述读契约，再做以下三个入口。这条读路径独立于远程 embedding，可以单独推进。

| 查询 | 必要输入与结果 |
|---|---|
| 当前事实 | 业务类型与名称条件，返回当前正文、ID、期限、替代/待确认状态，沿用插件现有的当前事实判定。 |
| 1 跳关系 | 节点 ID、方向和业务边标签，返回关系端点及正文摘要，工作区/会话 bookkeeping 不计为业务关系。 |
| 孤立实体 | 返回完整判定的无业务关系实体。超预算时明确报错，后续分批协议应保留“是否扫描完整”。 |

所有查询显示工作区、live/snapshot 来源、快照捕获时间/代际、实际返回条数和截断原因。408、413、422、429 分别呈现超时、响应过大、预算拒绝和容量忙。切库丢弃迟到结果，结果超界时给出缩小范围的操作方向。首期交付聚焦读取与诊断。

新版 HTML 稿可在这两个后端契约确定后，用一页演示来源切换、结果和错误状态。已有交互稿继续承载记忆编辑，避免把查询方案与写操作混在同一条流程。

## 有效 embedding 连接需要提供什么

提供完整 embeddings URL、模型名、实际输出维度和计费口径/免费额度。密钥在本机设置页或 DSH_TRIVIUM_EMBED_KEY 中配置。当前库维度为 1536，优先使用可直接输出该维度的配置。真实端点准备可以与前置修复并行。

测试依次验证接口/维度、插入与编辑后的向量对应、限流/超时降级，再对相同合成语料比较关键词+图与启用向量后的检索。记录召回、误召回、延迟、token/实际费用和批量写入成本。事实身份语料另作正负例验收。

真实付费运行使用 --budget 熔断，沿用本机每次 ¥3、Asia/Shanghai 每日 ¥10 的授权范围。价格或 usage 缺失时先确认可审计的费用口径。首轮采用隔离库，以明确范围的业务节点测试。
