# 0.8.4 — 设置页重构

2026-11-03。**只改前端呈现**：服务端逻辑、默认开关、数据库结构、模型工具、token 预算与决策替代判据一律未变。

## 变了什么

设置卡从"一个长页面 + 列表/召回两个标签"改成四个页面，宿主入口仍然只有一个（设置 → **Trivium 记忆**）。

| 页面 | 装什么 | 原来在哪 |
|---|---|---|
| **记忆库**（默认） | 工作区、搜索/类型/过期/已替代筛选、条目列表与编辑、归档/删除/合并、更正与撤销 | 列表标签 |
| **上下文** | 「这一轮实际发送」（真实送达 + 预算）、只读试算（候选、被丢弃原因、将发送文本） | 召回标签前半 |
| **运行记录** | 运行诊断（上次抽取/卡住/已自愈/上次地图注入）、维护检查、更正队列、恢复状态、记忆变化、召回轨迹 | 召回标签后半 + 无处安放的诊断 |
| **设置** | 记忆行为（注入策略 + 配置）、显示（界面语言）、数据（导出/导入/外部记忆）、向量（embedding）、关于（检查更新） | 常驻在长页面底部 |

其它：

- **Ctrl/Cmd+K**：命令面板，4 个页面 + 13 个分区入口；子串优先、子序列兜底；↑↓ 选择、Enter 跳转、Esc 关闭、Tab 锁在面板内；打开时焦点进输入框，关闭后归还。只导航，不写任何设置。
- **详情三档容器**：卡片 ≥1000px 时右侧粘性栏、720–999px 居中弹窗（Esc/遮罩关闭、焦点陷阱）、更窄时保持行内展开。分档按卡片自身宽度（ResizeObserver），不是窗口宽度——宿主设置弹窗固定约 600px。
- **视觉**：设计稿的 12 个颜色与 12px 圆角以 CSS 变量挂在卡片根节点，`ui.*` 全部带旧值回退，因此卡片跟随宿主明暗，卡片外（芯片页、宿主壳）不受影响。
- **设置分组**："检查更新"从第二位挪到最后；语言、注入策略、数据、向量不再藏在折叠里，折叠里只剩高级开关。

## 没变什么

- 四工具名称/参数/返回、`DIM=1536`、schema、`triviumdb` 版本均未动。
- 默认开关未动：注入默认关、抽取默认开、芯片默认关、embedding 默认关。
- 没有新增服务端接口，也没有新增写路径；面板的"新增"仍走既有的纯文本 `POST /chips`。
- 没有实现"严格创建记忆"（需要先定创建契约），也没有新增无法落地的按钮。

## 已知限制

1. **900–1199px 的弹窗档只在结构测试里验证**：宿主的设置弹窗固定约 600px，实机跳不到这一档。
2. **深色主题未实机验证**：本次截图与实跑都在浅色系统下；变量与回退是为深色写的，但没有肉眼确认。
3. **命令面板只导航**：不执行保存、导入、删除一类写操作，避免在面板里绕过确认。
4. **页面状态不持久**：刷新或重开设置回到记忆库；草稿在切页时保留。
5. 升级不需要迁移：没有 schema 变化，没有设置键变化。
