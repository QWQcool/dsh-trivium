## 1. 语义级去重：只能做"同一事件"这一层

先试过文本相似度，**实测否决**：

| 样本对 | bigram Jaccard |
|---|---|
| 真重复（同一改口的一句话两种措辞） | **0.258** |
| 两个不同事实（"负责人张三/李四，预算 5000/8000"同模板） | **0.444** |

相似度会把不同事实判成重复、把真重复判成不同，方向是反的。所以改用**来源**：

```
先看完全相同的 type+name+正文（重试）
否则：同一事件（messageId，缺失时用 seq）+ 同 type + 同 name
否则：同一事件 + 同 type + 已存节点本身有 supersedes 边（模型对同一次写入换了名字）
```

最后一条是本轮加的：真机里模型两次给同一句话起的名字不同（`上线方案 B` / `上线方案`），
名字匹配不上，但"一条消息产生两条都声称替代旧决策的事实"几乎只能是同一次写入。

`p67` **8/8**：改名改写折叠、不同名字不同事实不折叠、折叠后正文取更丰富的一版并保留旧正文为 history。
全量 **68/68**。
