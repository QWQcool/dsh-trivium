# W9 证据：可疑空回答重问一次

基线 `9cb6dfe`。真实模型复测 3 次，¥0.014993。

## 1. 问题

W8 的 r1 里，模型对 `这次上线按方案 A 走。` 和 `上一个方案不要了，走新的，用方案 B。`
**两次都返回 `{"candidates":[]}`**。空候选被当作"成功且无内容"，窗口被消费，两个决策直接消失。
这不是空的字符串（那是失败、会保留 pending），而是模型**明确说"没有东西可记"**。

## 2. 改法（`lib/extract.js`）

```
模型回 {"candidates":[]}
  且 规则层也没产出
  且 窗口里明显有决策（方案 X / 决定…走 / 按…走 / 不再使用 / 作废）
→ 再问一次（追加一行：上次判为无内容，请重读）
→ 第二次仍为空：消费窗口，但把 emptySuspicious 写进 lastExtract
```

三条边界：

- **最多重问一次**，不会无限循环；
- 重问**走同一套闸门**（凭据、日期、替换），不是绕过校验；
- 规则层已经写过的窗口**不重问**（避免为同一句话花第二次钱）；
- `looksLikeDecision` 是窄匹配，普通闲聊不会触发第二次调用。

`p66` **13/13**：重问后恢复、两次仍空且上报、闲聊只问一次、规则命中不重问、空字符串仍算失败。
全量 `run-all` **67/67**（其中一次跑出 66/67，未复现，见第 5 节）。

## 3. 真机复测（SPOKEN ×3，¥0.014993）

| 轮 | 抽取调用 | 节点 | 是否重问 | 回答 |
|---|---|---|---|---|
| r1 | 2 | 3 | 否 | ✓ B |
| r2 | **3** | 2 | **是** | ✗ 空回答 |
| r3 | 2 | 3 | 否 | ✓ B |

**r2 是重问生效的直接证据**：第一次 `{"candidates":[]}`，重问后返回了 `这次上线按方案 A 走。`，
事实没有丢；随后第二轮正常建链（`supersedes: "上线方案 A"`，retired=1）。

r2 的"回答为空"是**提问轮本身返回空文本**，与抽取无关，属于另一个问题（未修）。

## 4. 仍然存在

1. **同义不同文的重复**：r1、r3 各落了两条措辞不同的方案 B（`这次上线改走方案 B；之前定的方案 A 已废弃` /
   `这次上线改按方案 B 走，上一个方案（方案 A）已弃用`）。精确去重救不了它，需要语义级合并，本轮没做。
2. **提问轮空回答**（r2）未定位。
3. 重问只在"模型明确说没有"时触发；模型给出错误但非空的候选时不会重问。
