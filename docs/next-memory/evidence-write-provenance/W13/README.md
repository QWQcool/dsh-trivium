## 1. 三条 P1 的现象与根因

| 编号 | 现象 | 根因 |
|---|---|---|
| **P1-1** | 用户只说"发布负责人是张三"，候选写成"发布负责人**改为**张三"并附 `supersedes:"方案 A"` → 方案 A 被退休；代指目标同样 | `resolveExplicitSupersede` 的措辞证据算的是 `句子 或 候选正文`，候选可以自己给自己授权 |
| **P1-2** | "不再使用方案 A，改用方案 B；方案 B 的预算为 5000 元……" → 预算事实建了一条 `预算→方案 B` 的边，head 变成预算节点，短图里方案 B 消失 | 替换意图用"候选正文提到方案名"判定（`planNameOf(candidateText)`），提到新方案名即被当作替换意图 |
| **P1-3** | "别用方案 A，改用方案 B。""不要用方案 A，改用方案 B。" 返回 `discussion-or-question`，A 不退休；无关分句"日志格式沿用原样"也会否决前面的明确改口 | 否定词表把 `别用/不要用` 当成"讨论/保持"，且否定判定作用在**整句**而不是分句 |

结论必须直说：上一轮为了修 R-01/R-02，把判据做成了"整句一刀切"，于是同一批改动既放松了不该放松的地方（候选正文可自证），又收紧了不该收紧的地方（明确改口被否）。这是设计问题，不是漏测。

## 2. 修法（`lib/extract.js`）

1. **措辞证据只认用户分句**：新增 `clausesOf()` / `replacementClauses()`，按 `。；;！？` 切分；替换词、否定词、引号都在**同一分句内**判断。
   - 无关分句不再否决：`日志格式沿用原样` 与改口分句互不影响。
   - 候选正文**不再**能提供措辞证据（显式路径同步改掉）。
2. **否定词表纠正**：`别用 / 不要用` 从"非替换"里移除——它们本来就是"别再用它"的指令；保留 `不要换 / 别换 / 不换`（否定"替换"这个动作本身）。
3. **目标方向判定**：新增 `AWAY_CUES`（不再使用/别用/不用/弃用/作废…，目标在**词后**）与 `SWITCH_CUES`（改走/改为/改用/换成…，目标在**词前**）。
   - 候选不是替换句时：只能退休"用户说不要用的那个"，且候选正文必须提到它；
   - 候选是替换句时：排除候选正文里作为"改用目标"出现的方案。
   - 这一条同时修好 P1-2（预算只提到新方案 B，B 不是"被弃用"的目标 → 不退休）和保留真实改口（候选重述旧文并提到 A → 退休 A）。
