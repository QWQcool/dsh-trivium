## a. 在线零增益结论

- 原始online-rep3.json、online.json、50k输出和计划中的evidence-c目录均未回交本机/Git，不能重新判读原答案或验证usage。
- 在线脚本写成`const cwd = join(root, );`，所有场景/臂/重复共用一库；重复setup、归档和替代会跨单元干扰，不是隔离的90次实验。
- S02只检查“都可以”，否定句也通过；S07泛泛提“基线”即可；S10问题本来就带“增量”，判据未检查改变原因。零调用审计中三个明确不合格的合成答案全部通过旧判据。
- plain臂是人工精选的相关文本，工具臂需要从含噪声的图中检索，系统提示也不同。原S07纯文本只提基线/版本/种子，缺少工具库六条约定中的其它内容。不能把差异归因于有无图。
- default臂只传ctx_find/ctx_read两个读工具，不运行完整DSH会话、短地图或抽取；工具输出还截到1500字符。它不是插件完整默认配置成本。
- n=3、单模型、temperature=0、分数饱和不能证明等效；“9次比较全部30/30”不是脚本的实验单位。
- 14.7是按硬编码单价算出的费用比，不是token比。S07“只败1/3”和“那1次通过”表述也不一致；无原答案不能决定假阳性的确切数量。

本轮只修隔离、S07材料、关系构造断言、完整答案/逐调用usage留存、预算检查位置，并加audit-only。未重跑付费实验，未宣称字符串匹配已升级为语义评分。新实验应先固定事实项rubric，处理否定、时态、原因及噪声；保留完整输出/工具轨迹，盲审后再比较。旧数据不能因脚本修复而追认。

## b. 性能诊断与优先级

2s/10s预注册门槛不改。旧50k数字若真实，查询和重开都不合格；本轮不把缺少原始制品的历史值包装为新实测。

新增bench-retrieval-stages，固定1k合成图，在独立进程临时包装原生方法计数并finally恢复，无embedding或模型请求：

| 层 | 本轮观察 |
|---|---|
| 查询 | keyword区间约94–97ms，三条查询总计约109–184ms；entity-anchor区间约13–35ms |
| 导入 | 1k节点触发1000次buildTextIndex、1002次allNodeIds |
| 重开 | 对1001个节点重做indexText/indexKeyword，build一次；该fixture开库40.66ms |
| 只做机制探索 | 原生loadTextIndex:true打开18.35ms，有文本命中；绕过插件初始化，不是等价优化验收 |

阶段区间包含候选接纳及插桩成本，不是严格CPU分摊。旧表1k→50k的查询p50约增长41倍，不支持“n^1.75”查询复杂度拟合。建议先研究持久索引有效性/损坏恢复和批量build，再优化有界候选/关键词与锚点扫描；不直接删重建。

旧bench-scale的reopenMs包含同进程close+open，不能叫OS冷启动；peakRssMb只是末尾采样；tdbMb统计整个.dsh。repeat改变边种子，只能用于跨图形态覆盖，不能证明同库检索随机或稳定。本轮新增子进程设置隔离，未重定义旧阈值或伪造历史峰值。

## d. G4的两个层次

原脚本先建立c2→c1，又用ensureLink建立同一边；false是已有边去重。反向c1→c2能造真环，内部store helper不同于模型工具ctx_link。

更严重的公开入口是ctx_remember：link_label为任意string，原来没有像ctx_link一样拒绝supersedes，能写未经确认、分叉或类型错误的关系。本轮在写节点前拒绝，合法业务连接仍可用，不改工具schema。

另从Git归档的原始e4d3e09代码做独立复现，仅调用两次公开ctx_remember（不注入原生边）：两次都返回Remembered，旧节点出现两个后继；integrity报告fork-predecessor，但currentHeadOf仍返回ok:true，并由ctx_find输出其中一条为current。输出保存在public-fork-baseline.json并纳入证据摘要。这直接否定“公开路径无法制造坏链”。

旧currentHeadOf只取第一条后继、只向前走，分叉/超长链的头或中间节点可能被投影为正常。本轮只对所在链做双向验证，循环、分叉、超过32跳、非decision端点、缺失节点拒绝投影；不扫描或修复全库、不删关系，正常非版本实体照常解析。p31修前6/18，修后18/18。

公开路径核查：ctx_link原守卫保留；ctx_remember已补；HTTP supersede委托工作区队列与校验；JSON/JSONL走映射后整图预检及事务；正文/删除/合并保护由p19–p23覆盖。原生db.link/commitTransaction及内部ensureLink可用于模拟损坏，不能称为模型公开工具。这里是已审路径与回归，不是对所有未来输入的形式证明。

G4脚本改为真正构造反向环和33跳损坏链，纳入violations并失败非零退出；不再把“没造出来”算通过。
