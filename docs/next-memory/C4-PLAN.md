# C4 对照预注册（写于跑真实模型之前）

日期：2026-10-29。基线 `534bcb1`（0.8.0 已发布）。本文件在任何 C4 付费请求发出之前定稿；
跑完只允许追加实测结果，不允许回头改判据、场景或臂来凑数。

## 0. 本轮要回答的问题

1. 两个指定对手能不能在**本机**装起来、并走真实宿主钩子（不是只读 README）。
2. 在**同一批合成事实、同一判据、同一模型**下，图记忆工具路径相对「把同样事实写成一段文本」是否有质量差异？
3. 两个对手在**各自默认预算**与**等预算**下，注入的 token 与费用差多少。
4. 哪些问题本轮**答不了**，必须记未覆盖。

不做：安装即跑的排行榜、真实使用质量声明、对我方 27/10 个工具面的横跑（见 §6）。

## 2. 语料与场景（冻结）

- 语料：`scripts/quality-fixtures.mjs` 的**同一份**合成事实，10 场景中取 **6 个**：S01、S04、S05、S06、S07、S09。
- 排除 S02/S10（需要修订链）与 S08（需要归档语义）：三个对手都没有等价的「当前/历史」与归档投影，
  跑它们测的是「有没有这个能力」，不是「检索准不准」。这条排除是**预注册的**，不是看到结果后删的。
- 每场景额外 6 条无关事实（`旁支项目`）照旧注入，用于测噪音耐受。
- 判据：`grade()` 结构化字段严格比较，金标不改。
- 隔离：每场景/臂独立库（临时目录），并在写入前断言库路径在临时根下。

## 3. 参照臂（6 个，全部不提供工具）

| 臂 | 注入 | 预算 |

**统一不给工具**：一次只动「注入/召回」这一个变量。对手的工具面常驻税（0 / 27 个）与
按需读取不混进来；这限制必须写进结论，不能把 6 臂结果说成「整体产品对比」。

## 4. 模型、预算与计费

- 模型 `deepseek-flash`，`thinking: disabled`，`temperature=0`，`max_tokens=600`，每格 **n=1**（先跑一轮，预算允许再加）。
- 计费：只认 provider 返回的 `usage`；单价沿用 2026-10-29 官方高峰价（输入 2 / 缓存命中 0.04 / 输出 8 元每百万）。
- 预算：整轮真实请求 ≤ **15 元**；每个请求发前按 UTF-8 字节上界预留费用并落盘，超预算立即停止（不发请求）。
- 请求失败或 usage 缺失：保留全额预留并停止，不无界重试。
- 6 臂 × 6 场景 = **36 格**，预计单格 1 次调用（无工具循环），成本量级与 COST-QUALITY 的 152 次/0.0997 元同阶。

## 5. 记录项

每格记录：臂、场景、注入文本（或完整投影）的 sha256 与本地估算 token、模型原始回答、`grade`、
逐调用 `usage` 与估算费用、注入来源（我方 pre-step / GoodMemory `itemCount` / dsh-memory 命中条数）。

汇总口径：严格通过数 / 6、注入 token 均值、调用费用；三者分开报，不合成单一分数。

## 6. 预注册的未覆盖项

1. **工具面未对照**：dsh-memory 的 27 个工具、我方 4 个工具都没有提供给模型；「按需读取」路径本轮不测。
2. **修订/归档语义未对照**：见 §2 排除的三个场景。
3. **抽取质量未对照**：三方都是直接种事实（GoodMemory 走它自己的 `remember` 规则抽取，因此必须用
   `记住：…` 这一它认的显式标记；内容不变，但**入库形态由其抽取决定**，这是对手默认行为，不是我们改写）。
4. **真实宿主端到端**：本轮用「真实插件 `apply` + 真实 `pre-step` + 宿主 peer 0.2.1-rc.4」，
   不是完整 `dsh web` 会话，也不含 UI/审批/压缩。
5. **多模型、多重复**：n=1、单一模型，方差未知。
6. **长期成本**：不含对手的后台整理（dsh-memory `batchExtract`、可选的 LLM 提取）。
