## 第一片：宿主与采集预检（零模型调用）

- 固定源码提交、Node/宿主/内核版本；专用 DSH_HOME、设置、profile、工作区和端口，禁止使用真实 .dsh 或真实会话。
- 通过实际宿主事件记录 map、工具定义、用户/助手/插件消息、抽取、数据库写入、pre-step、compaction/end、重试和最终 provider usage；保存首轮与压缩后上下文。
- 所有 adapter 写入前验证路径，查询前验证输入/持久事实集合。缺任何阶段记录或发现越界路径就停止，不能退回假钩子然后称真实宿主。
- 用本地受控模型桩验证采集完整、失败保留、重复通知与预算锁止。该片不产生质量或节省结论。

## 第二片：小样本质量预检

- 合成会话包含中文姓名、金额/端口、否定改口、指代、助手确认、成功/失败工具证据、长文本头/中/尾及多条并列。
- 使用真实生产调度器；不预先直接种入正确答案。每臂独立会话和库，运行顺序交错。
- 固定事实字段和原始语句，分别记录漏记、错记、重复、过期/替代误用、跨库泄漏和最终回答。严格字段与人工语义复核并列，歧义样本不偷偷改金标。
- 不因“不调用模型”就判降本；先确保正确事实真的落库且跨压缩后可用。

## 第三片：同质量净费用

- 在质量预检通过后，测同一批任务的 5/10/20 轮。明确 no-memory-full、受控 compaction 与 memory-compaction 的差异，保持其余宿主配置一致。
- 工具 schema、短地图、注入历史、压缩/摘要、后台抽取、回答和失败重试全部计费；峰/谷归一化并列，不伪称供应商账单。
- 一次完整实验预算不超过 **15 元**，启动前按最大输出与最贵适用价格估算全矩阵。每请求先落盘预留；缺 usage、价格未知、供应商/路径异常、预计超限立即停止，回交已知花费及未决预留。
- 不能达到同质量时不计算“无损节省”；达标后也只报告样本内结果，不发布通用百分比。
