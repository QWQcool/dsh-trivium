# 回交审查清单

以下项目对应 IMPLEMENTATION_PLAN.md。任何“失败即阻断”项不通过，都不能认定升级完成。

## 失败即阻断

- [ ] 基线确为本地0.4.22及0.8.11，issue #3与48项专项回归仍通过。
- [ ] 默认芯片/召回关闭；打开来源/历史/诊断不会调用模型、embedding或注入上下文。
- [ ] 地图默认≤400；同轮pins+recall合计≤300，包含包装文本。
- [ ] 同一节点跨渠道只出现一次；同一用户轮的工具循环不重复注入。
- [ ] 两条内容相同但事件id不同的用户消息不被误当成同一轮。
- [ ] 注入失败后能够重试；compaction后可以重建；fork不继承错误的去重状态。
- [ ] `ctx_find`≤1200估算token；记录/JSON不被粗暴截成无效片段，截断有提示。`ctx_read`保留全文能力，同一正文不因新metadata增加默认输出。
- [ ] 新来源字段不会因payload直接JSON.stringify而泄漏到默认工具输出。
- [ ] 四工具数量和参数集合不增加；工具schema估算token不超过基线。
- [ ] supersedes方向为新→旧；不与same_as、archived或until混为一谈。
- [ ] supersedes不被放入默认BUSINESS_EDGES导致历史全量展开。
- [ ] 跨workspace、非decision、循环、自环、分叉、32跳溢出被拒绝。
- [ ] 替代写入由服务端校验、workspace队列与原生事务保护，重复/丢响应重试幂等。
- [ ] 并发ETag失配返回409，不能覆盖另一窗口的操作。
- [ ] 自动抽取、手工编辑、merge与导入不能绕过历史正文保护。
- [ ] 当前版本归档或到期不自动复活旧决策；旧pin不会被静默换成新pin。
- [ ] 撤销只移除指定supersedes关系，保留其它边，且不拆错已有后续版本。
- [ ] JSON/JSONL导入有图验证与冲突预检；失败不产生半条版本链。
- [ ] 原生事务与独立文本索引的原子性边界表述正确，失败可观察、可重建。
- [ ] 无新增云服务、后台LLM调用、0.9 beta依赖或真实用户库迁移。

## 来源与诊断

- [ ] 缺少来源显示缺少；不会生成不存在的会话、作者或引文。
- [ ] 来源文本用纯文本渲染，路径/节点/会话访问服从工作区边界。
- [ ] trace实际反映发生过的管线阶段，不伪造BM25/向量百分比。
- [ ] trace上限20次/10分钟/每条64KiB；阶段明细有100条上限与truncated。
- [ ] 只读预览不写库、不运行工具、不请求embedding；无向量时明确显示语义未运行。
- [ ] 本机来源默认不进入可提交的Git JSONL；导出策略有说明。
- [ ] 所有预算数字标明估算，不能当作真实账单或模型token测量。

## 前端

- [ ] 保留DSH设置入口、配置折叠及既有导入/导出/归档/删除能力。
- [ ] 列表、内容、来源、决策历史、召回检查与原型的信息层级一致。
- [ ] 已过期与已替代使用独立标签；历史节点有当前版本定位。
- [ ] 确认替代展示旧/新两条已有决策；无隐式生成或自动批准。
- [ ] 空数据、无来源、来源失效、无trace、服务异常、409冲突可见且有操作方向。
- [ ] 桌面与窄屏无横向溢出；中英文和暗色可用。
- [ ] 弹窗键盘可达、Escape关闭、焦点恢复；提交中禁用重复动作。
- [ ] HTML的演示工具栏、虚构数据、设计标注未误植进正式产品。

## 必须提供的证据

- [ ] 按ACCEPTANCE_CASES.json逐项提供结果与日志位置。
- [ ] 默认场景、双通道去重、过期过滤、版本映射、同轮第二步、压缩重建的实际注入文本和估算值。
- [ ] 16组基线测试、新增测试、消费项目工具调用检查日志。
- [ ] 1440px桌面、900px窄桌面、390px移动宽度及暗色截图。
- [ ] 替代成功、撤销、409冲突和来源失效的交互录像或步骤截图。
- [ ] 数据格式/降级说明、尚未完成的限制、可复现命令。

审查不会要求本轮提交性能基准。若报告只有页面截图、没有预算与版本关系的行为证据，不能通过。
