- [ ] 基线 commit、package / lock / 内核 / 宿主一致；用户已有工作未被覆盖。

- [ ] 同轮工具步骤／消息对象重建不重发预算；相同文本但不同用户事件是新轮。
- [ ] commit 幂等、失败不消费、旧 generation 失效；同轮 compaction 只使用剩余额度。
- [ ] 新 id 对应新正文／状态／路径；自动召回、预览、find 行为一致，显式历史 pin / read 保持原选择。

- [ ] ETag 409 和 operationId 重试幂等真实生效；历史正文保护覆盖抽取、编辑、合并和导入。
- [ ] JSON / JSONL 均测试 URI 身份、映射后整图校验、事务失败无部分写入和重复导入。
- [ ] 图事务与文本索引／JSONL 派生边界分清；失败可见、可重试、重开恢复，不假称所有文件原子。

## 来源、诊断和界面

- [ ] 来源只用已知事实；缺少／不可访问分开；不补造作者、引文或 deep link。
- [ ] 只读预览不调用模型／embedding，显示 semantic 未运行；trace 不编造 BM25／向量贡献百分比。
- [ ] 跨工作区／会话访问规则与来源导出策略保持；来源文本按文本呈现。
- [ ] Settings 管理动作、配置折叠、条目／召回、内容／来源／历史层级清楚。
- [ ] 已过期和已替代分开；确认替代显示两条已有事实；409 保留选择且可刷新恢复。
- [ ] 900px / 1440px、浅深色、中英文按改动范围走查；390px 仍记为不支持，不用无溢出冒充可用。
- [ ] Tab / Shift+Tab 可达、焦点可见、Enter 可操作、Escape 关闭、焦点返回；提交中不重复写入。
- [ ] 空数据、错误、预算不足、旁路待恢复与加载状态不互相冒充；异步请求不会把旧工作区结果显示在新工作区。
- [ ] fork 不被表述为数据库隔离；父子会话共享工作区事实库，pin 默认不继承、显式继承有验证。
