## 三、R3 第一片：真实宿主 + 采集预检（零付费，**16/16 通过**）

做法（全部在 `.tmp/r3/`，独立 `DSH_HOME`）：

- 用本机真实宿主 `@deepseek-ai/dsh@0.2.1-rc.4` 的 `headless` bundle 启动，profile 同时挂**本仓库 dsh-trivium** 与只读事件探针（只订阅观察类事件；`agent/request`、`llm/stream`、`system-prompt/assemble` 这类 bail/transform 事件一旦订阅就会破坏宿主，已排除）。
- 模型端点用 `DEEPSEEK_BASE_URL` 指向本地受控桩（Anthropic Messages SSE），**零真实调用**；桩记录每个线上请求（`x-api-key` 脱敏）。
- 同一 session 连跑 3 轮，第 3 轮由桩返回一次 `context_length_exceeded`，让宿主走真实的 overflow→压缩→重试。

| 验收点 | 实测 |
|---|---|
| 宿主启动/会话 | `session/created`，会话文件在隔离 home |

| 用户消息上线 | 含原文 |
