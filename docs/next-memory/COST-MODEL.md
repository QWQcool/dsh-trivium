# 成本口径：一律换算成谷价，峰价只作上界

日期：2026-10-29。价目抓取自 [DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 1. 官方价目（元 / 百万 tokens）

| `deepseek-flash` 高峰 | 2 | 0.04 | 8 |
| `deepseek-flash` 空闲 | **1** | **0.02** | **4** |

- 空闲价 = 高峰价的一半；
- **高峰时段**：北京时间 周一至周五（不含法定节假日）09:00–12:00、14:00–18:00；其余（含周末）为空闲。
- 旧别名 `deepseek-chat` 当前被路由到 `deepseek-flash`，按 flash 计费（实测回执 `model=deepseek-flash`）。

## 2. 本项目的记账约定（用户 2026-10-29 指定）

1. **对外报成本一律用谷价**，即使那次实际跑在峰价——避免「今天跑的比昨天贵一倍」的失真；
2. 峰价数值同时保留，作为**上界**与预算守卫；
3. 换算只依赖 token 用量，**不按运行时刻猜**：每笔请求回执同时写 `costPeak` / `costOffpeak`；
   历史账本由 `scripts/cost-normalize.mjs` 重算，不需要知道当时几点；
4. 节假日无法在本地安全判定（需要节假日表），因此**不判断**，只做双价记录。

## 4. 复现

```bash
# 任意账本 → 双价重算（不联网）
node scripts/cost-normalize.mjs --out=docs/evidence/cost-normalized.json <ledger.json...>
```

脚本对每个臂输出 `calls / promptTokens / cachedTokens / completionTokens / cnyPeak / cnyOffpeak`，
并在 `grandTotal` 给出总计；`docs/evidence/` 下的账本都由它生成，文档里的数字与之一致。

## 5. 一句话

**峰价是上界，谷价是对外口径；两者之差正好 2 倍（flash 与 v4-pro 均如此），所以任何跨时段相加都必须先换算。**
