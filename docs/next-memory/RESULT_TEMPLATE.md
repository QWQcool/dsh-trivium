## 缺陷与改动证据

每个缺陷写触发条件、修复前复现、根因、相关文件、修复后的同一断言。区分代码阅读推断和实际复现，不用“测试全绿”替代具体证据。

涉及上下文时附实际发送文本、累计估算 token、同轮多步骤和失败重试；涉及版本链或导入时附身份映射、事务失败前后逻辑快照、重开验证和派生恢复。
