## 正式发布

当前修改位于 `codex/fix-memory-recall-0.4.22`，尚未提交。先审阅并提交代码，再按仓库惯例推送与打 tag。确认发布时，使用已验证的包：

```sh
npm publish ./dist/dsh-trivium-0.4.22.tgz --registry=https://registry.npmjs.org
```

dry-run 不会发布，也不验证正式发布时的账号权限或 OTP。源码若再修改，应重新打包和执行消费项目检查，不能继续使用本页的旧校验值。

## 用户升级与旧数据

停止 DSH 后备份 `.dsh/trivium.tdb*` 整个文件组，再更新插件并重启。旧版本误写的期限可以从设置中的「显示过期决策」找到，清空 `until` 并保存；不必改写正文日期。`ctx_find` 默认能检索到相关过期历史，但会标记 `stale` 并降权，不能把它直接当作当前约定。
