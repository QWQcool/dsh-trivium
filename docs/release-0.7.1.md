# dsh-trivium 0.7.1

状态：**已发布**。npm `latest` 已指向 `0.7.1`，GitHub `main` 与 `v0.7.1` 已更新。发布于北京时间 **2026-10-28 18:22:01**。

## 范围

这是 0.7.0 的可靠性补丁，承接 [缺陷审查](bug-audit-2026-10-28.md) 和 [可靠性收尾](reliability-0.7.1-backend.md)。不引入新模型工具、外部服务、默认自动召回或新数据格式；内核继续精确锁定 `triviumdb@0.9.0-beta.3`。

- JSONL 不再逐条提交事实；与 JSON 共用 URI 身份、最终图校验和原子事务。事务失败不留半条链、不更新成功 hash，失败输入不被自动写出覆盖；恢复原文件或移除失败输入后可以重试。
- 合法归档是可用性状态，不是版本链损坏。JSON/JSONL 保存归档链端点与关系，避免克隆后旧版本复活；新建替代操作仍拒绝归档端点。
- 待发更正合并到最新状态，同一轮的不同变化不会误去重；较早的在途通知不能消费更新的待发通知。32 条边可解析为 33 个节点，第 33 条边写入前拒绝。
- 已投递决策在后续 pre-step 自然到期时排入短更正；更正先于重复 pins 使用原有每轮 300 估算 token。注入关闭或本轮预算不足时保留并解释原因，不绕过关闭选择，不承诺无条件下一条送达。
- 旁路 health、最后注入/抽取/计划/trace 按工作区返回。显式生成旁路失败同样进入 health，设置页展示恢复提示。
- 设置面板绑定已显示的工作区；修复快速搜索与写后刷新竞态。替代/撤销发生 409 后同步列表并失效旧缓存，保留弹窗选择但不自动重提；已替代节点按当前筛选隐藏。条目标题可键盘展开，永久删除确认一致；替代弹窗限制 Tab 焦点，Escape 只关闭内层并返回仍存在的触发器，否则回到面板标题；多版本历史不再显示“没有历史”。原生下拉选项使用成对宿主主题颜色，修复深色白底不可读。
- 期限清理 CLI 默认 dry-run 使用只读句柄，不同步旁路、不写事实或设置；两个维护 CLI 的帮助命令不打开数据库。
- 文档统一当前入口，迁移历史引用后单独删除三个重复草稿；保留原始验收与冻结 JSON。抽取的本地/联网边界已准确说明。

## 升级

停止使用该库的宿主，备份工作区完整 `.dsh/trivium.tdb*` 文件组，再通过 DSH 升级并重启。JSONL 是业务事实交换文件，不含全部本机数据，不能替代完整备份。

```sh
dsh plugin --profile web add dsh-trivium
```

JSON 图 `version: 2` 和 JSONL `v: 2` 不变。补丁不会自动修复此前已经丢失的正文或合并身份；体检报告结构问题后应使用原始导出或完整备份恢复，不能靠猜测重建。

## 验证与边界

最终回归 26/26，p23 47 项、p24 12 项、p25 32 项；最终 tarball 干净安装与 13 项真实 peers 验证通过。用户手工确认键盘、深色/900px、两浏览器冲突与冲突后列表刷新。实际 Web HTTP 导入文件锁失败/恢复通过；完整 UI 导入故障与独立安装桌面制品全流程未覆盖。详细证据见 [0.7.1 验收](verification-0.7.1.md)。受控 pre-step 不等于真实模型质量评测。

仍只支持 ≥900px，一个库一个读写进程；投递与更正账本仍为进程内状态。自然到期跟踪限于本进程已投递的 pin/recall 事实，不扫描整个会话历史，不新增后台计时器。质量/负载和 B–E 功能开发仍是后续批次。
